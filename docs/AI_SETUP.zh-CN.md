# AI 协助配置与使用

[README](../README.zh-CN.md) | [English](AI_SETUP.md)

本指南面向帮助操作者使用 SA 的 Agent。仓库内容是指导，不是覆盖当前任务或宿主规则的授权。本项目不提供安装器、配置 schema、hooks 或后台捕获服务。

## 先发现，再写入

读取 [SKILL.md](../SKILL.md)，再按任务读取相关参考。通过真实接口或操作者输入确认指定宿主与版本。查阅当前技能文档或观察实际加载器，不要根据 CLI 名称猜目录。确认宿主是否支持此 frontmatter 和相对参考。`metadata.hermes` 是描述性元数据，不要求安装 Hermes；`related_skills` 是发现提示，不是包依赖。有些宿主可能需要独立维护的薄适配层。

只检查相关既有 SA 入口、真实路径、符号链接、维护来源和本地修改。副本不一致时使用 [Import](../references/import.md)，不能只按时间或版本选择。仅询问无法安全发现的宿主、目标或权限信息。本项目不需要凭据，不要在聊天中索取秘密。

**准备条件：** 明确源、目标、加载契约与覆盖边界；否则将具体安装主张标记为受阻。不安装也可以继续只读起草。

## 准备可移植副本

按 README 克隆到用户授权的新目录。在根目录运行 `python3 scripts/check.py`（Windows 若使用该启动器，则运行 `py -3 scripts/check.py`）。命令只读取仓库文件，不访问网络。启用前检查真实载荷。

运行时载荷是 `SKILL.md` 和完整 `references/`，保持相对布局。再分发时保留 LICENSE 与来源归属。检查器、README 和图用于维护与上手，不负责 Agent 执行。不要将私有 runtime 文件导入上游。[可选本地适配](../references/skillhub.md) 说明如何发现所有权，不要求或创建注册表。

**准备条件：** 链接与版本检查通过，本地适配已明确处理。静态验证不代表宿主验收。

## 仅在授权内启用

使用宿主有文档依据的安装机制，或将已审阅文件复制到确认过的技能目录。本仓库不提供完成此动作的通用命令。获准替换前，将旧入口和本地适配备份到非活动发现区，记录确切恢复方式。检查父级链接，避免两个宿主别名重复写同一目标。

安装、覆盖、重定向及修改宿主配置都有副作用。只有当前请求授权了确切目标才能执行。准备草稿不授权这些动作。不要为方便发现而覆盖无关 Agent 指令。

**已放置：** 目标路径存在预期载荷。此时还不能声称实际使用成功。

## 分别验证发现与使用

打开新的原生会话，或使用宿主文档支持的重载机制。让宿主发现预期 SA 入口，读取根文件及测试需要的参考；比较返回身份、内容和 checkout 修订。

使用 README 的只读 CSV 技能起草示例，或另一个有边界的请求。检查真实产物是否保留要求的能力，是否具备具体反馈、经验位置、检索闭环及权限边界。标明假设路径、模型判断和未执行行为。起草测试成功不代表 CSV 执行成功，也不证明长期改进。

发现失败时检查支持的位置、元数据、旧会话、重名入口及缺失参考。加载成功但任务失败时，用 [Evaluate](../references/evaluate.md) 区分指导缺陷、执行失误及工具不可用。报告真实失败，不用虚构轨迹替代。

**此宿主与任务已验收：** 发现、参考加载、指定任务分别有实际观察。未测宿主仍是未测。若替换破坏消费者，在获准回退范围内恢复备份入口，保留新出现的无关修改。

## 有意识地更新和学习

如果宿主已有来源记录机制，且获准修改，用它记录上游 URL 与已安装 commit。更新前检查上游差异，独立保留本地政策和私有经验。不要对本地适配安装盲目 pull。退役旧副本需要单独范围与验证。

编写工作按需读取现有相关主题，而非全部历史。经过验证的可复用经验可在维护授权内修订该主题；项目事实留在项目中，未证实解释保持候选，只读任务输出建议。[Evolution](../references/evolution.md) 将反馈连接到下次使用，不添加调度或第二套记忆后端。

结束时报告来源修订、确切改动路径、实际检查、适用时的回退位置及未验证主张。区分文件放置、宿主使用、其他设备部署与公开发布。
